    How it works

    What is WebAssembly (WASM)?

    A compact binary instruction format that every modern browser runs at close to native speed, inside the same sandbox as JavaScript. Code written in C, C++ or Rust can be compiled to it once and run on any device. Two large C projects run here as WebAssembly: the CPython interpreter (via Pyodide) and the GMP math library (via gmp-wasm, and again inside Pyodide).

    What is GMP? And MPFR?

    The GNU Multiple Precision Arithmetic Library is the standard C library for arbitrarily large numbers, tuned over three decades and relied on by compilers such as GCC and by computer algebra systems. It switches multiplication algorithm as numbers grow: schoolbook, Karatsuba, several Toom-Cook variants, then FFT. MPFR is built on GMP and adds big floating-point numbers with correctly rounded results.

    What are Pyodide and gmpy2?

    Pyodide is CPython, the standard Python interpreter, compiled to WebAssembly so real Python runs in the browser. gmpy2 is a Python library that wraps GMP and MPFR. The pure-Python card measures Python’s own int; the gmpy2 card measures GMP with a thin layer of Python on top.

    What is a BigInt?

    JavaScript’s built-in integer of unlimited size, written with an n suffix (123n). In Chrome and Edge, multiplying huge BigInts moves from schoolbook to Karatsuba, Toom-Cook and FFT-based algorithms as numbers grow, which is why plain JavaScript keeps up surprisingly well. Other browsers implement BigInt differently, so their results (and size limits) vary.

    What is a Web Worker?

    A background thread for JavaScript. A page’s own JavaScript shares one thread with scrolling and clicks, so a long calculation there freezes everything. Here each method lives in its own worker: the page stays responsive, several methods use separate CPU cores at once, and Cancel simply terminates the worker.

    What is fast doubling?

    Two identities, F(2k) = F(k)·(2F(k+1) − F(k)) and F(2k+1) = F(k)² + F(k+1)², jump from position k straight to 2k or 2k+1. Reading the bits of n from the top, each bit doubles the position and adds one if the bit is set, so F(1,000,000) takes 20 steps instead of a million additions. The matrix method walks the same bits but does more than twice the multiplications per step.

    Three fast doublings, three very different speeds

    The JavaScript, pure-Python and GMP cards run essentially the same algorithm, about 20 steps for n = 1,000,000. What differs is the big-number library underneath, and above all how it multiplies. CPython’s int only implements Karatsuba (roughly n1.58). V8’s BigInt adds Toom-Cook and FFT multiplication. GMP has tuned code for every size range, and its Fibonacci routine is built from squarings, which are cheaper than general multiplications.

    gmpy2 and mpz_fib_ui call the very same GMP function, yet gmp-wasm is much faster. The algorithm isn’t the difference; the build is. gmp-wasm compiles GMP with 64-bit limbs (the “digits” GMP works in), compiler optimizations, and size thresholds tuned by GMP’s own tuneup program running in WebAssembly. Pyodide’s recipe uses the default 32-bit limbs, untuned thresholds, and passes only CFLAGS="-fPIC", which replaces GMP’s usual optimization flags. Both builds also have to skip GMP’s hand-written assembly, which WebAssembly can’t use, so native GMP would be faster still.

    Why log₂ n steps is not log₂ n time

    The numbers double in size at every step, so the last step alone costs about as much as all the earlier ones combined. The total comes to a small constant times M(n), the cost of one big multiplication. That is why the multiplication algorithm decides the race. Binet’s formula with MPFR is the exception: it works at full precision from the start, so every one of its multiplications is full-size.

    Printing is the slow part

    F(100,000,000) has almost 21 million digits. Converting a binary number to decimal takes GMP several times longer than computing it, and since 2022 Python refuses by default to print integers over 4,300 digits, because its conversion used to be quadratic and could be abused to stall servers. So each worker gets the digit count and the first and last 30 digits from one power of ten and one division instead. Results are cross-checked on those digits: methods that agree get a ✓.

    Dangerous mode

    Warning: normally, any method expected to take more than 2 minutes or about 1.5 GB of memory is skipped. Dangerous mode runs it anyway. That can take hours, use many gigabytes of RAM, freeze or crash this tab or the whole browser, and slow down everything else on your computer. Cancel stops a run immediately, unless the browser runs out of memory first.
